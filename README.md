# OVI · Lógica Computacional

Objeto Virtual de Información (OVI) desarrollado para la asignatura **Desarrollo Web 1**, Universidad de Córdoba, sobre el tema **Lógica Computacional**.

## Autor

- **Nombre:** Mateo Saez Beleño
- **Correo:** msaezbeleno@gmail.com
- **Programa:** Ingeniería de Sistemas, VI semestre

## Tecnologías utilizadas

- HTML5
- CSS3 (variables CSS, Flexbox, Grid, diseño responsive)
- Sin JavaScript, según lo indicado por el docente. Las actividades interactivas se lograron únicamente con HTML y CSS (`:checked`, `<details>`/`<summary>`).

## Estructura del proyecto

```
mi-proyecto-ovi/
├── index.html              # Inicio
├── multimedia.html         # Videos del curso
├── actividades.html        # 3 actividades interactivas (solo HTML/CSS)
├── autores.html            # Datos del autor
├── README.md
├── .gitignore
├── css/
│   ├── variables.css       # Tokens de color, tipografía y espaciado
│   └── styles.css          # Estilos generales del sitio
├── img/                    # Imágenes utilizadas en las lecturas y autores
└── lecturas/
    ├── index.html                     # Índice de lecturas
    ├── poo.html                       # Lectura 1: Programación Orientada a Objetos
    ├── parametros-condicionales.html  # Lectura 2: Parámetros y condicionales
    ├── clases-instancias.html         # Lectura 3: Clases e instancias
    ├── ciclos.html                    # Lectura 4: Ciclos (bucles)
    └── tablas-verdad.html             # Lectura 5: Tablas de verdad
```

## Secciones del sitio

1. **Inicio:** introducción al tema y a los objetivos del OVI.
2. **Lecturas:** cinco páginas con contenido, imágenes y citas en formato APA.
3. **Multimedia:** dos secciones de video (introducción general y serie del curso de la Universidad de Córdoba).
4. **Actividades:** cuestionario verdadero/falso, acordeón de autoevaluación y tarjetas de volteo con términos clave.
5. **Autores:** datos del autor del OVI.

## Publicación

Este sitio está publicado con GitHub Pages. Los enlaces al repositorio y al sitio publicado se encuentran en el archivo `enlaces.txt` incluido en la entrega.
