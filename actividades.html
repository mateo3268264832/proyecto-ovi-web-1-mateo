Actividades

Tres ejercicios sencillos, hechos solo con HTML y CSS, para repasar lo visto en las lecturas.

1

Verdadero o falso

Elige una opción en cada pregunta y aparecerá la retroalimentación de inmediato.

1. Una clase puede usarse para crear varios objetos distintos.

¡Correcto! Una clase es un molde: a partir de ella se pueden crear tantos objetos (instancias) como se necesiten.
No es correcto. Recuerda que una clase es un molde reutilizable: de una sola clase pueden salir muchos objetos distintos.

2. Un condicional siempre necesita una expresión que sea verdadera o falsa.

¡Correcto! Un condicional evalúa una expresión lógica que solo puede tomar dos valores: verdadero o falso.
No es correcto. Todo condicional depende de una expresión lógica que es, necesariamente, verdadera o falsa.

3. Un ciclo for se usa cuando no se sabe cuántas veces se repetirá una acción.

¡Correcto! El for se usa cuando ya se sabe cuántas repeticiones se necesitan; para lo contrario se usa un while.
No es correcto. Ese es justamente el caso del bucle while; el for se usa cuando el número de repeticiones ya se conoce.
2

Autoevaluación paso a paso

Piensa tu propia respuesta antes de abrir cada pregunta.

¿Cuál es la diferencia entre una clase y un objeto?

La clase es la plantilla o el molde que define atributos y métodos; el objeto es cada elemento concreto creado a partir de esa plantilla, también llamado instancia.

¿Para qué sirve un parámetro en una función?

Permite que la función reciba información externa cada vez que se ejecuta, en lugar de trabajar siempre con los mismos valores fijos.

¿Qué diferencia hay entre un bucle for y uno while?

El for se usa cuando se conoce de antemano el número de repeticiones; el while se usa cuando la repetición depende de que una condición se siga cumpliendo.

¿Cuándo es falsa una conjunción (p ∧ q)?

Siempre que al menos una de las dos proposiciones sea falsa. Solo es verdadera cuando p y q son verdaderas a la vez.
