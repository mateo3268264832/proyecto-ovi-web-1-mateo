Programación Orientada a Objetos

El paradigma que organiza el código alrededor de clases y objetos.

La Programación Orientada a Objetos (POO) es un paradigma —una forma de pensar y organizar el código— que propone modelar un programa como un conjunto de objetos que interactúan entre sí, en lugar de una simple lista de instrucciones que se ejecutan una tras otra. Cada objeto agrupa, en un mismo lugar, los datos que lo describen y las acciones que puede realizar.

Para crear un objeto primero se necesita una clase: una plantilla o molde que define qué información va a tener el objeto (sus atributos) y qué puede hacer (sus métodos). Por ejemplo, una clase Estudiante podría definir atributos como nombre y semestre, y métodos como inscribirse a una materia. A partir de esa única clase se pueden crear tantos objetos —tantos estudiantes concretos— como se necesiten.

Idea clave

Según IBM Documentation, en la POO los programas se diseñan usando objetos que interactúan entre sí, donde cada objeto representa una instancia de una clase, y las clases pueden aprovechar relaciones de jerarquía y herencia para compartir características entre sí.

Este enfoque trae varias ventajas frente a la programación puramente secuencial. Martínez Canelo (2020) explica que la POO facilita la reutilización de código, porque una clase ya escrita puede usarse para crear múltiples objetos o servir de base a nuevas clases mediante la herencia, y que esto favorece programas más ordenados y fáciles de mantener a medida que crecen.

Los cuatro pilares que suelen citarse en la POO son la abstracción (modelar solo lo relevante del problema), el encapsulamiento (proteger los datos internos de un objeto), la herencia (crear clases nuevas a partir de otras ya existentes) y el polimorfismo (que un mismo método se comporte distinto según el objeto que lo ejecute). A lo largo de las siguientes lecturas de este OVI se irán viendo, en la práctica, varias de estas ideas: cómo se definen parámetros, cómo se crean instancias y cómo se repiten acciones dentro de una clase.
