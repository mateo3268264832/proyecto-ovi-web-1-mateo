Ciclos (bucles)

La instrucción que se repite mientras una condición se mantenga.

Un ciclo o bucle es una estructura de control que permite ejecutar un mismo bloque de instrucciones varias veces, sin necesidad de escribirlo repetidamente. KeepCoding define los bucles como estructuras que repiten una acción mientras se cumpla una condición determinada, evitando así que el programador tenga que duplicar código para tareas que se repiten.

Existen distintos tipos de ciclos, y todos comparten la misma idea de fondo aunque cambien la forma de controlarla. Euroinnova explica esta clasificación distinguiendo, entre otros, el bucle for (se usa cuando se conoce de antemano cuántas veces se debe repetir la acción) y el bucle while (se usa cuando la repetición depende de que una condición se siga cumpliendo, sin saber de antemano cuántas veces ocurrirá).

Idea clave

Todo ciclo necesita una condición de parada. Sin ella, el programa entraría en un bucle infinito: la misma trampa lógica que un condicional mal planteado, pero repetida sin fin.

Los ciclos son especialmente útiles junto con la programación orientada a objetos: por ejemplo, para recorrer una lista de instancias (todos los estudiantes de un curso) y aplicarles el mismo método a cada una (calcular su promedio), sin tener que escribir esa operación una vez por cada estudiante. Esta combinación de clases, condicionales y ciclos es, en la práctica, la base de casi cualquier programa.
