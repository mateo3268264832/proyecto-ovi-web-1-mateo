Parámetros y condicionales

Cómo se le pasa información a una función y cómo se toman decisiones.

Parámetros: la información que recibe una función

Un parámetro es un valor que una función necesita para poder ejecutar su tarea. Llamas (s. f.) lo describe como el mecanismo que permite que una función reciba datos externos al momento de ser invocada, en lugar de trabajar siempre con valores fijos escritos dentro de su código. Por ejemplo, una función calcularPromedio(nota1, nota2, nota3) necesita esas tres notas como parámetros para poder devolver un resultado.

Gracias a los parámetros, una misma función puede reutilizarse con datos distintos cada vez que se llama, en lugar de escribir una función nueva para cada caso particular. Esto conecta directamente con la idea de reutilización de código que ya se vio en la lectura sobre POO: los métodos de una clase casi siempre reciben parámetros para operar sobre datos concretos.

Condicionales: tomar decisiones dentro del código

Un condicional es una estructura que evalúa si una condición es verdadera o falsa y, según el resultado, ejecuta un bloque de instrucciones u otro. Luis Llamas explica que la programación condicional es la que permite que un programa reaccione de forma distinta ante distintas situaciones, en lugar de ejecutar siempre la misma secuencia de pasos sin importar los datos de entrada.

Idea clave

Toda estructura condicional (si / si no) se apoya en una expresión que solo puede tomar dos valores: verdadero o falso. Esa expresión es, exactamente, lo que estudian las tablas de verdad de la última lectura de este OVI.

El ejemplo más clásico de un condicional es comparar dos valores para decidir un ganador: si la puntuación del Jugador 1 es mayor que la del Jugador 2, se muestra un mensaje de felicitación para el primero; si esa condición es falsa, se sigue el camino alternativo (else) y se felicita al segundo jugador. El diagrama de flujo de la derecha ilustra exactamente ese caso.
